0 Conectar Página

Gere o token na Meta e cole aqui. Ele é salvo criptografado no servidor — esta página nunca volta a mostrar o token.

Como gerar Page ID e token
  1. Abra o Graph API Explorer logado na conta que administra a Página.
  2. Em Meta App, escolha um aplicativo seu (crie um em developers.facebook.com, tipo Business, se ainda não tiver).
  3. Clique em Generate Access Token e marque: pages_show_list, pages_read_engagement, pages_manage_posts.
  4. Autorize e selecione a Página.
  5. No Explorer, faça GET em me?fields=id,name — o id é o Page ID (se o token já for da Página).
  6. Copie o Access Token do topo e cole abaixo. Se o token for de usuário e você tiver várias Páginas, o painel pede para escolher.

Token do Explorer costuma durar poucas horas. Para uso contínuo, gere um token de Página no Gerenciador de Negócios (Usuários do sistema → Gerar token) com as mesmas permissões.
